頭版｜人物

兩年半企業官網切版實務，從設計稿一路做到上線；目前主要使用 Vue 3 與 React。

我是承哲，設計科系畢業後轉職前端，目前主要開發技術是 Vue 3 與 React。在行銷公司擔任前端的兩年半期間，獨立完成多個企業官網的切版與功能實作，也負責維護與修復公司既有的舊專案。

設計背景是我在前端工作上的優勢。從 Amos 的網頁切版班開始，我養成的習慣是理解每個 CSS 屬性的行為，而不是靠試錯堆出結果，這讓我在還原設計稿與處理複雜版面時，知道自己每一行為什麼這樣寫。

在切版這塊，AI 目前還是有明顯不足，版面一複雜，產出的間距、對齊與 RWD 斷點往往需要人工重修，反覆修正也會耗費多餘的時間與 token。過去兩年半的切版經驗讓我在處理複雜版面時更有條理，能避免 AI 協作產出多餘的程式碼，而不是一再丟回去讓它重試。閱讀《Code Complete》後，我開始關注程式的內聚力、命名與可維護性，並整理成一套自己的開發規範。

2025 年 12 月起，我在好想工作室 Web Camp 擔任進駐學員。即使部分內容過去接觸過，我仍選擇從基礎重新建立，這次補強的不只是語法，還包括測試撰寫、I/O 設計這些過去實務中沒機會深入的工程觀念，以及拆解問題的流程。

我也曾參與台南市衛生局菸酒業務單位的流程優化專案，實地訪談承辦人員釐清作業痛點，產出 prototype 並參與提案，協助把使用者需求轉化為具體的系統設計方向。對我來說，寫程式是手段，找到真正的問題並解決它才是價值所在。
